# PixelShrink — Image Compressor

Premium, responsive, GitHub Pages-ready image compressor.

## Features
- JPG, PNG and WebP input
- Multiple image selection
- Browser-side compression with Canvas
- Quality slider
- Output format selection
- Before/after file sizes
- Individual and bulk downloads
- Dark/light theme
- Responsive mobile UI
- AdSense placeholder areas
- Privacy and Terms pages

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for deployment.

## AdSense
The visible ad boxes are placeholders. After your site is approved by Google AdSense, replace the placeholder areas in `index.html` with the exact AdSense code provided in your AdSense account. Do not copy a random publisher ID.

## Before publishing
- Replace PixelShrink with your final brand name if desired.
- Add your real contact email.
- Review Privacy Policy/Terms for your actual business.
- Add Google's required consent/cookie implementation where applicable.
- Test the compressor on mobile and desktop.
